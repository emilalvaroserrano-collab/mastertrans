# MultilinguaHe Flutter Edition

A high-performance Flutter cross-platform mobile and desktop application for real-time dual-speaker translation, featuring:
- **Real-time Dual Translation**: Instant translation between 10+ languages with Medical and General modes.
- **Supertonic 3 Voice & Prosody Profiles**: Custom voice modulation (Female F1-F5, Male M1-M5) and prosody dynamics (Balanced, Clinical, Empathetic, Expressive, Articulate, Fast).
- **Edge AI Integration**: Support for local Gemma 3 1B on Ollama and Gemini Cloud Fallback.
- **Transcription & History**: Audio recording simulation, translation history, and PDF/text export.

## Getting Started

1. Ensure you have the Flutter SDK installed (`flutter --version`).
2. Install dependencies:
   ```bash
   flutter pub get
   ```
3. Run the app on your connected device or emulator:
   ```bash
   flutter run
   ```
